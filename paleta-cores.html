Paleta de Cores - Levaê

Cor principal

Azul #3B82F6

O azul foi escolhido como cor principal do Levaê porque remete a confiança, segurança e tecnologia — valores essenciais para quem confia seu trajeto a um motorista que muitas vezes acabou de conhecer. Além disso, o azul é associado ao céu aberto e ao deslocamento, reforçando a ideia de rotas, estradas e conexão entre cidades, que é a proposta central da plataforma.

Tipo de paleta

Para as cores do Levaê, foi escolhida uma paleta monocromática, utilizando principalmente diferentes tons de azul junto com cores neutras, como branco e cinza. Dessa forma, é possível utilizar tons mais escuros para textos e destaques e tons mais claros para fundos e outros elementos da interface.

Essa escolha mantém a interface limpa e consistente, sem disputar atenção com muitas cores diferentes — comum em apps de mobilidade, onde clareza e leitura rápida são prioridade.

Uso em CSS

As cores são centralizadas em variáveis CSS (:root) e reutilizadas em todo o projeto através de var(), garantindo consistência e facilidade de manutenção.

:root {
  --azul-escuro: #0A2540;
  --azul: #3B82F6;
  --cinza-claro: #F1F5F9;
  --branco: #FFFFFF;
  --cinza: #64748B;
}

header.rota-header {
  background: var(--azul-escuro);
}

a.voltar {
  background: var(--azul);
}
