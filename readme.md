# LEVAÊ

Plataforma web que conecta passageiros e motoristas para facilitar 
caronas entre Irecê e cidades da região.

## Estrutura do Projeto

Projeto WEB/
├── assets/
│   ├── css/       -> arquivos de estilo (CSS)
│   └── imagens/   -> imagens usadas no site
├── favicon.ico    -> ícone exibido na aba do navegador
├── index.html     -> página inicial do projeto
└── readme.md      -> este arquivo, com a documentação do projeto

## Sobre as pastas

- **assets/css**: guarda os arquivos de estilo que definem a 
  aparência do site.
- **assets/imagens**: guarda as imagens usadas no projeto, como 
  logos e ícones.
- **favicon.ico**: fica na raiz do projeto porque é referenciado 
  diretamente no `<head>` do index.html.
